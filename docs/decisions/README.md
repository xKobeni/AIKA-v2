# Architecture decisions

The [foundation specification](../AIKA_V2_FOUNDATION.md) contains the baseline ADRs. Use the [implementation roadmap](../AIKA_V2_IMPLEMENTATION_PHASES.md) to determine when an accepted decision applies.

When implementation needs to diverge from an architectural contract, propose a short Architecture Decision Record in this directory before changing the contract. Reference the affected foundation section or ADR. Record the date, status, problem, options considered, proposed choice, reasons, consequences, and how to verify the change. Include data, permission, compatibility, and recovery effects where relevant.

Record the approved decision and update the affected specification or explicitly supersede the previous ADR. Routine implementation choices within an existing contract can be recorded in the checkpoint report.
